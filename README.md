# Card Vault online

Personal sports card library: https://jpantonello.github.io/card-vault/

- `index.html` – the app (built from the PC app with `src/build.py` + `src/shim.js`)
- `library/` – the shared set library (sets.json and the TCDB checklists)
- Data and photos live in Supabase (login by email link).
